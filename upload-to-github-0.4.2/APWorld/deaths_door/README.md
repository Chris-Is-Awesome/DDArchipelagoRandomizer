# Death's Door apworld

This is the [Archipelago](https://archipelago.gg/) apworld for [Death's Door](https://store.steampowered.com/app/894020/Deaths_Door/). It works together with the Death's Door Archipelago mod.

Setup instructions for the mod and the apworld, and descriptions of every yaml option, are in the main README:
https://github.com/Chris-Is-Awesome/DDArchipelagoRandomizer#readme

Download the mod and `deaths_door.apworld` from the same release:
https://github.com/Chris-Is-Awesome/DDArchipelagoRandomizer/releases/latest
